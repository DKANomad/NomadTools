# NomadTools

[![OBS Compatibility](https://github.com/DKANomad/NomadTools/actions/workflows/obs-compatibility.yml/badge.svg)](https://github.com/DKANomad/NomadTools/actions/workflows/obs-compatibility.yml)

OBS plugin for quality of life tools when using OBS for streaming/recording

## Installation

1. Close OBS Studio.
2. Download `nomad-tools.zip` from the latest release.
3. Extract the archive into the OBS Studio installation directory, usually `C:\Program Files\obs-studio`.
4. Start OBS Studio and enable the NomadTools dock from the Docks menu.

Release builds currently support Windows x64.

## Continuous integration

Future `v*` tags produce a Windows x64 artifact and attach `nomad-tools.zip` to the matching GitHub release. A weekly compatibility workflow also compiles the plugin against the latest stable OBS release and the current OBS `master` branch.
